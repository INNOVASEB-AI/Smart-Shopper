# Smart Shopper SA

A modern, responsive web application for smart grocery shopping in South Africa. Compare prices across major retailers and manage your shopping lists efficiently.

## Features

### 🛒 **Shopping List Management**
- Create and manage multiple shopping lists
- Add items with voice dictation support
- Mark items as completed with beautiful animations
- Progress tracking for each list

### 🔍 **Smart Search**
- Search across multiple South African retailers
- Real-time price comparison
- Product suggestions and autocomplete
- Voice search capabilities

### 💳 **Loyalty Cards**
- Store and manage loyalty card information
- Barcode scanning for easy card addition
- Quick access to card details

### 🎨 **Modern UI/UX**
- **Splash Screen**: Beautiful app launch experience with animated logo
- Dark/Light mode support
- Responsive design for all devices
- Smooth animations and transitions
- Accessibility features

### 🔐 **User Authentication**
- Secure login and registration
- Firebase authentication integration
- Data synchronization across devices

## Splash Screen

The app features a beautiful splash screen that displays on launch:

- **White Logo**: Centered display of the Smart Shopper SA logo
- **Animated Elements**: Smooth fade-in animations for logo, title, and loading spinner
- **Loading Indicator**: Spinning animation to show app is loading
- **Tap to Dismiss**: Users can tap anywhere to skip the splash screen
- **Auto-dismiss**: Automatically disappears after 3 seconds
- **Responsive**: Adapts to different screen sizes and orientations
- **Theme Support**: Matches the current dark/light theme

### Splash Screen Features:
- 3-second display duration
- Smooth fade-out animation
- Mobile-friendly tap-to-dismiss
- Loading spinner animation
- Responsive design for all screen sizes
- Theme-aware styling (dark/light mode)

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm start`
4. Open your browser to `http://localhost:8000`

## Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Tailwind CSS, Animate.css
- **Authentication**: Firebase Auth
- **Database**: Firebase Firestore
- **Icons**: Heroicons
- **Fonts**: Inter (Google Fonts)

## Browser Support

- Chrome (recommended)
- Firefox
- Safari
- Edge
- Mobile browsers (iOS Safari, Chrome Mobile)
