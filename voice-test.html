Voice Dictation Test

This page tests the voice dictation functionality for the Smart Shopper app.

Click the button above to start voice dictation

Instructions:

  1. Click the voice button to start dictation
  2. Speak clearly into your microphone
  3. The recognized text will appear in the input field
  4. Say "done", "stop", or "finished" to stop dictation
  5. Or click the button again to stop manually

Test Items to Try:

  • Single item: "milk"
  • Single item: "bread"
  • Multiple items: "milk next bread next apples"
  • Multiple items: "chicken breast next toilet paper next bananas"
  • Multiple items: "eggs next milk next butter next cheese"

How to Separate Items:

Say "next" between each item to add multiple items at once:

  • Example: "milk next bread next apples"
  • Result: Adds 3 separate items: milk, bread, apples

How to Stop Voice Dictation:

Say any of these commands to stop listening:

  • "done"
  • "stop"
  • "finished"
  • "end"
  • "complete"
  • "that's all"
